# Contributing to CourierOS

Thank you for your interest in contributing to CourierOS!

## Development Process

1. **Fork & Clone**
   ```bash
   git clone https://github.com/d3v3sh-711/courier-tracking-system.git
   ```

2. **Create Feature Branch**
   ```bash
   git checkout -b feature/my-new-feature
   ```

3. **Commit Changes**
   Follow conventional commit conventions:
   - `feat:` New feature
   - `fix:` Bug fix
   - `docs:` Documentation update
   - `refactor:` Code cleanup

4. **Verify Build**
   ```bash
   npm run build
   ```

5. **Submit Pull Request**
   Open a pull request on GitHub against the `main` branch.
